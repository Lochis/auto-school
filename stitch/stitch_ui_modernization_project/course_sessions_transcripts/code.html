Class Notes — 26F - COMP231 - (SEC. 401) - Lab

Overview

This lab session featured a student-led presentation by Group 1 on “How to Conduct a User Role Modeling Workshop,” covering the conceptual foundations of user role modeling from the Cohn textbook, a worked example of the full role-modeling process (brainstorm → organize → consolidate → refine) using a household shared-expenses app, and the written/video deliverables required for the assignment. The session ended with a Q&A clarifying scope decisions and video format expectations, followed by a reminder about the upcoming assignment deadline and breakout-room group work.

Key Topics
User Role Modeling — Conceptual Understanding [10:00]
  • Definition: A user role is the part someone plays when using a product, including their goals, needs, and behaviors in context. One person can hold multiple roles simultaneously.
  • Roles vs. Personas: A role represents functional interaction patterns, while a persona is a concrete fictional profile built atop an archetype.
  • Cohn Framework Stages: Brainstorm initial candidates freely, organize spatial clusters, consolidate overlaps, and refine into primary persona profiles.
